Client Search

The hub starts with one searchable surface across Billing, PSA, and dual-LOB onboarding clients.

  • Search any client by name and point out the LOB badges.
  • Use the date filter to scope recent activity to 30, 60, 90, or 180 days.
  • Show the snapshot timestamp so people know they are seeing refreshed data.
Say this

"Instead of asking which system has the latest note, we start with the client and pull the operating record around them."

BillingPSADual-LOB

Client Overview

The client view brings project health, status, owners, forecast dates, balances, and useful source links into a single page.

  • Point to SA, PM, DE, CSA, status, health score, and forecast/graduation dates.
  • For PSA clients, show onboarding health, forecast health, sentiment, overdue milestones, and long-term RTS flags.
  • Use quick links to Notion, Wrike, tracker pages, Fireflies, and source records when available.
Say this

"This is designed for repeated operational use: what is the state, who owns it, what changed, and where do I go next?"

Evidence Feed

The hub ties status back to source evidence instead of relying on stale summary fields.

  • Show Billing briefs, PSA call briefs, recent interactions, open Zendesk tickets, and PSA tickets.
  • Point out risk/action extraction from call records and briefs.
  • Use a ticket or call link to show that summaries can be audited back to source systems.
Say this

"The important part is not just summarization. It is traceability. If we flag a risk, the source context is one click away."

PSA Milestones and Critical Path

PSA clients include training milestone progress, overdue work, phase grouping, and critical path coverage.

  • Show milestone percentage and total milestone count.
  • Scroll to the training milestone table and point out status, due date, completion date, phase, and overdue flags.
  • Open the milestone edit modal if you want to show the write-back workflow.
Say this

"This turns a project tracker into a leadership-readable progress model without hiding the underlying task list."

2,126Critical pathOverdue flags

Action Logging and Edits

The hub is not only read-only. It supports controlled updates where the team needs quick operational capture.

  • Use "Log Interaction" to capture a call, email, meeting, Zendesk note, sentiment, outcome, and next-step context.
  • Use milestone edit for PSA task status, planned due date, completion date, and notes.
  • Call out that these workflows route through controlled automation rather than manual spreadsheet drift.
Say this

"The goal is to keep the operating record current from the place people are already reviewing the work."

Client Tracker Pages

From the hub, a client can branch into a client-readable tracker view for Billing or PSA.

  • Open the tracker link from a Billing client to show status and milestone timeline.
  • Open the PSA tracker from a PSA client to show phase-grouped milestone progress.
  • Explain that the hub is the internal operating cockpit; trackers are cleaner views for client/project context.
Say this

"We can move from internal detail to a simpler client-facing progress view without rebuilding the data twice."

DE View

The new DE View flips the hub from client search into a line-of-business work queue for data engineering progress.

  • Switch to the DE View tab and show that dual-LOB clients split into separate PSA and Billing rows.
  • For PSA, point to exactly Data Access, Data Load, and Data Review.
  • For Billing, point to exactly Data Load, Comparative, and Bill-Out Support.
  • Be clear that Billing task state is currently inferred from existing hub signals.
Say this

"This gives DE a single queue without mixing PSA and Billing work together. Same client, separate LOB work when needed."

The simplest framing

Use this if you need to end crisply.
Onboarding Hub is the operating layer between source systems and action. It does not replace Notion, Wrike, tickets, or call records. It reduces the time spent hunting through them, makes client status auditable, and gives the team a shared view of what needs attention next.
